# Glass Dash — Modern Admin Dashboard

A modern, responsive, and visually appealing Admin Dashboard built using React.js, JavaScript, HTML5, and CSS3.

Glass Dash is designed to simulate a real-world SaaS/Admin Panel experience with analytics tracking, user management, product administration, coupon generation, and profile settings — all wrapped inside a premium dark-themed interface.

---

## Live Demo

🔗 https://glassdash-admin-dashboard.netlify.app/

## GitHub Repository

🔗 https://github.com/Karan-oop/GlassDash_Admin_Dashboard

---

## Project Overview

Modern businesses require powerful dashboards to monitor performance, manage users, track analytics, and handle products efficiently.

Glass Dash provides a clean and scalable solution by combining modern UI/UX principles with reusable React components and responsive layouts.

The project focuses on creating a professional dashboard experience similar to those used in SaaS products, e-commerce platforms, CRM systems, and enterprise management tools.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Karan-oop/GlassDash_Admin_Dashboard.git
```

Navigate to project folder

```bash
cd GlassDash_Admin_Dashboard
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
